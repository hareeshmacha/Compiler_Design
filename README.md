# Compiler Design

Welcome to the Compiler Design project! This repository contains an incremental compiler built from scratch, tracking various compilation phases from lexical analysis up to code generation. 

## Project Phases

This repository is built incrementally. Each phase of the compiler has its own dedicated directory and documentation:

- [**Phase 1: Lexical Analyzer**](./phase1-lexer/README.md): A Lexical Analyzer built using `flex` in C++. It parses a custom C-like source language into a stream of tokens, identifying keywords, operators, and formatting lexical errors.
- *(Future phases like parsers, semantic analyzers, and code generators will be added here as the project progresses)*
